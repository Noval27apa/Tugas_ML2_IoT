## Deskripsi Proyek
Proyek ini melakukan klasifikasi serangan pada jaringan IoT menggunakan model Decision Tree (Tuned). Eksperimen ini mencakup tahap pemrosesan data, seleksi fitur, pelatihan model, serta deployment menggunakan Streamlit.

## Dataset
Dataset yang digunakan dalam penelitian ini bersumber dari Mendeley Data.
Anda dapat mengunduh dataset aslinya melalui tautan berikut:
[Download Dataset IoT - Mendeley Data](https://data.mendeley.com/public-files/datasets/7m58kxs742/files/4d57de6a-a140-4607-bf38-146899f1a723/file_downloaded)

## Cara Menjalankan
1. Pastikan semua library terinstal: `pip install -r requirements.txt`
2. Jalankan aplikasi Streamlit: `streamlit run app.py`
